## 미니 프로젝트 — 서울 쏠림 현상: 20대 이동 및 사회 인식 분석
**미니 프로젝트 대회 1위 (전체 8개 팀)**

### 프로젝트 주제

20대 인구의 서울 집중 현상을 데이터로 분석하고, 온라인 여론(유튜브 댓글, 뉴스 기사)에서 사회적 인식을 파악하는 프로젝트. 기존 인구 이동 연구가 수치 데이터 중심이었다면, 여기에 **실제 대중의 반응을 텍스트 데이터로 함께 분석**한 점이 차별점이다.

### 프로젝트 기간

2024.07.11 ~ 2024.07.15 (1일 집중 작업 후 발표)

### 팀 구성

6명 (발표: 팀원 / 본인 담당: 데이터 시각화 — 단어 분석 및 시각화 수행)

### 기능적 요소

- KOSIS 20대 인구 이동 데이터 기반 수도권 집중 추이 시각화
- 유튜브 '서울 쏠림 현상' 관련 영상 댓글 크롤링 -> 핵심 키워드 빈도 분석
- 네이버 뉴스 기사 제목 크롤링 -> 키워드 빈도 분석
- 유튜브, 뉴스 데이터 비교 시각화 (막대 그래프, 원형 차트, 워드클라우드)

### 프로젝트 진행 절차

**1단계 — 데이터 수집**
- Selenium + BeautifulSoup으로 유튜브 댓글 크롤링 (무한 스크롤 처리, CSV 저장)
- 네이버 뉴스 기사 제목 크롤링

**2단계 — 텍스트 전처리 및 단어 분석**
- KoNLPy(Okt) 형태소 분석기로 명사 추출
- 불용어 처리 후 2글자 이상 단어만 집계
- groupby로 단어 빈도 집계표 생성

**3단계 — 시각화**
- Plotly로 유튜브, 뉴스 단어 빈도 TOP20 막대 그래프 및 원형 차트 생성
- 서브플롯으로 두 데이터 소스 나란히 비교
- WordCloud로 유튜브, 뉴스 워드클라우드 생성 (마스크 이미지 적용)

**4단계 — 발표**
- 팀 전체 결과 취합 후 발표 진행

### 활용 기술 및 도구

| 구분 | 내용 |
|------|------|
| **크롤링** | Selenium, BeautifulSoup, pandas |
| **텍스트 분석** | KoNLPy (Okt), 형태소 분석, 불용어 처리 |
| **시각화** | Plotly, matplotlib, seaborn, WordCloud |
| **환경** | Google Colab, Python |

### 프로젝트 주요 성과

- 전체 8개 팀 중 **미니 프로젝트 대회 1위** 수상
- 수도권으로의 20대 인구 집중이 지속적으로 심화되고 있음을 데이터로 확인
- 유튜브 댓글, 뉴스 기사 모두에서 '서울', '지방', '교육', '일자리' 등 키워드 다수 등장 -> 교육, 취업 문제가 핵심 원인임을 여론 데이터로 뒷받침

### 힘들었던 점 및 아쉬웠던 점

**유튜브, 뉴스 데이터 불균형**
유튜브 댓글 수에 비해 뉴스 기사 제목 수집 건수가 너무 적어, 두 데이터를 통합 분석했을 때 결과가 유튜브 데이터와 거의 동일하게 나왔다. 통합 분석 결과는 최종 발표에서 제외했다.

**뉴스 크롤링 방식의 한계**
기사 본문이나 댓글이 아닌 제목만 수집한 것이 아쉬웠다. 본문까지 수집했다면 더 풍부한 키워드 분석이 가능했을 것이다.

**작업 중 데이터 유실**
시각화 결과물을 더 보기 좋게 수정하는 과정에서 저장 오류로 일부 작업물이 날아갔다.

### 기술적 개선 가능성

- 뉴스 기사 본문 및 댓글까지 수집 범위 확장
- VADER, KoBERT 등을 활용한 감성 분석(긍정/부정) 추가
- 시계열 데이터와 결합해 여론 변화 추이 분석
